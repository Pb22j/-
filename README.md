# 👁️ بصير — Baseer

> **محاكي السوق السعودي (تاسي) للتوعية المالية**
> تعلّم التداول في بيئة افتراضية آمنة، مع وكيل ذكي يحميك من الأخطاء قبل ارتكابها.

محاكي تداول تعليمي بأسعار **حقيقية** من سوق تاسي (2010–2012)، مبني على نظام تصميم
بصير الورقي (قصّ ومزّق)، مع طبقة وكلاء متعدّدين وطبقة أمان تمنع أي توصية مالية.

## الباقات

باقتان فقط، بلا فخاخ تسعير. **الأرقام تقولها بدون مقابل**.

| | المبلغ | اللي فيها |
|---|---|---|

## النظام متعدد الوكلاء

```
                    ┌──────────────┐
   سؤال المستخدم ──▶│  المنسّق     │──▶ وكيل المعرفة      (RAG · ٢٥ مدخلاً من كتب حقيقية)
                    │ orchestrator │──▶ وكيل بناء المراحل  (يبني مرحلة من طلب المستخدم)
                    └──────┬───────┘──▶ وكيل الأخبار        (قصص مبنية على حركات حقيقية)
                           │
                           ▼
                    ┌──────────────┐
                    │  طبقة الأمان │  ← JS في الواجهة + Python في الخادم
                    └──────┬───────┘
                           ▼
                    ┌──────────────┐
                    │ وكيل المراقب │  ← Rules R1–R9، صامت إلا عند الخطأ
                    └──────────────┘
```

**وكيل المعرفة (RAG)** — يقترب من ٢٥ درساً مستخلصاً من كتب حقيقية
(*One Up on Wall Street*, *The Intelligent Investor*, *Technical Analysis of the Financial Markets*,
*Manias Panics and Crashes*, *Poor Charlie's Almanark*, …). يسترجع بالـ BM25 مع
تطبيع عربي، يرد بمبدأ + رقم المستخدم + سؤال، **ويذكر الكتاب**.

**وكيل بناء المراحل** — يحوّل «ما فهمت وقف الخسارة، ابني لي مرحلة» إلى مرحلة
قابلة للعب مربوطة بمدخل في المكتبة، مع خطة بديلة عند الفشل.

**وكيل الأخبار** — لا يخترع شيئاً: يفحص بيانات OHLCV الحقيقية، يستخرج أكبر
الحركات اليومية (≥ ٣.٢٪)، ويصوغ لكل حركة قصة مؤسسية بتاريخها الحقيقي. فتشوف
الخبر، وتقدر تعيد那一天 في العالم المفتوح، وتلاقي السعر فعلاً تحرّك.

**وكيل المراقب (صامت)** — يراقب كل أمر ويطلّق فقط عند خطأ، بأرقام المستخدم:

| القاعدة | الشرط |
|---|---|
| R1 / R1-soft | سهم واحد > 50% / > 35% من المحفظة |
| R2 | شراء بعد ٣ جلسات صاعدة متتالية (FOMO) |
| R3 | بيع بعد هبوط يوم واحد (Panic Sell) |
| R4 | محفظة من سهم واحد |
| R5 | سيولة نقدية < 5% |
| R6 | صفقة واحدة > 25% من رأس المال |
| R7 | شراء على قمة العشرة أيام |
| R9 | نقد زائد > 60% |

كل تحذير يقتبس مدخله من المكتبة وينتهي بسؤال — لا بقرار.

## 🛡️ طبقة الأمان — Compliance Middleware

الوكلاء **يُقال لهم** ما يُسمح لهم بقوله، وطبقة الأمان هي ما **يفرض** ذلك.
الفحص مرتين: في الواجهة قبل العرض، وعلى الخادم قبل الإرجاع — لأن الاعتماد على
فحص الواجهة وحده يتجاوزه أي عميل آخر.

**تحظر:** توصيات شراء/بيع · الأسعار المستهدفة · العوائد المضمونة · لغة الضخ · المحتوى غير القانوني
**تسمح:** التعليم · شرح الاستراتيجيات · إدارة المخاطر · تحليل محفظتك **الافتراضية** · بيانات تاسي التاريخية

عند الحظر يُعرض ردّ بصيرinstead من النص المولّد — ويبدأ بـ «هذي توصية، وما بجاي أعطيها لك».

## 🎬 مسار الـ Demo — 3 دقائق للحُكّام

افتح `http://localhost:5173`، ثم:

| الوقت | الخطوة | ما يجب أن تراه |
|---|---|---|
| `00:00–00:20` | **\#choose** | 3 بطاقات (مبتدئ / متوسط / خبير) + سؤال بصير برو + زر افتح الشات |
| `00:20–01:00` | ادخل **خبير** | محاكي tاسي: شارت HD، pricing tape، لوحة أوامر. اشترِ 100 سهم → **مراقب صامت** يطلق R2 ("دخل بعد 3 جلسات صاعدة") |
| `01:00–01:40` | `#chat`، اختر **وكيل المراحل**، اكتب "نبني مرحلة عن وقف الخسارة" | الـ agent يبني stage ببيانات tاسي الفعلية — 3 خيارات لنفس التجارة، 3 عواقب مختلفة |
| `01:40–02:20` | اضغط **العب المرحلة** | شارت tاسي الحقيقي على اليمين، beats تشتغل تلقائياً (أو زر اليوم التالي) |
| `02:20–02:50` | ارجع لـ **خريطة الرحلة** | "مراحل بناها بصير لك" — المرحلة الجديدة محفوظة مع نجومك |
| `02:50–03:00` | `#plans` | باقتان فقط: مجاني · خبير — لا تزييف |

## 🚀 التشغيل

### ١) الباك-إند (اختياري — الواجهة تعمل بدونه)

```bash
cd backend
python -m venv venv
.\venv\Scripts\Activate.ps1        # Windows
pip install -r requirements.txt
cp .env.example .env                # ضع المفاتيح لو تبي ردود حية
python main.py                      # → http://localhost:8000
```

### ٢) الواجهة

```bash
cd frontend
npm install
npm run dev                         # → http://localhost:5173
```

### المفاتيح

| المفتاح | الاستخدام | بدونه؟ |
|---|---|---|
| `MINIMAX_API_KEY` | ردود حيّة من MiniMax-M3 | ✅ الواجهة تعمل offline |
| `GEMINI_API_KEY` | بديل + الصوت ثنائي الاتجاه | ✅ اختياري |

> **بدون أي مفتاح** المشروع يعمل بالكامل: التداول، المراحل، الشارت، المراقب،
> مكتبة المعرفة، بناء المراحل، وبوابة الأخبار. الوكلاء يردّون بمركّب حتمي
> من قاعدة المعرفة، وتظهر علامة «بدون اتصال» بصراحة في كل رد.

### إعادة توليد البيانات

```bash
python scripts/process_data.py      # Excel → frontend/public/data/market_data.json
```

## 🎨 نظام التصميم

مأخوذ حرفياً من مجلد **Baseer Design System** — لا Tailwind ولا shades خارجية:

| الرمز | القيمة | الدلالة |
|---|---|---|
| `--cream` | `#F2EFE3` | الأرض |
| `--ink` | `#1A1A1A` | النص |
| `--blue` | `#3C5AA6` | الإجراء الأساسي |
| `--orange` | `#E8833A` | بصير والمكافآت |
| `--green` | `#4F8F5E` | الربح |
| `--red` | `#C63B2D` | الخسارة |

أنصاف أقطار **صفر دائماً** — softness تأتي من حافة القصّ فقط (`--cut-1…4`,
`--circle`, `--torn`). ظلال `--lift` فقط. بلا تدرّجات ولا blur.

**قواعد الكتابة:** لهجة سعودية بيضاء · بلا إيموجي · أرقام غربية بفواصل en-US ·
كلمة «ريال» **بعد** الرقم · سهم `↓`/`↑` بدل `+`/`−` · تقدّم بالنجوم لا بدرجة.

- ❌ لا تداول بأموال حقيقية — أبداً
- ❌ لا ربط حساب بنكي — أبداً
